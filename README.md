# Matrimonio — design system

Visual system for the ZG Wedding app: a public cover, a mobile-first guest site and the couple's planning tool. Direction: editorial, Amalfi coast — majolica tiles, lemons, a ceramic plate and terracotta on a warm off-white page. Two themes: **Costa** (light) and **Noche** (dark).

**See it live:** https://njarvis93.github.io/zg-wedding-design-system/ — palette in both themes, type, every component working, and the assets. The site (`index.html`) reads the files in `project/` directly, so it updates with every push to `main`.

## Install in the front

Install a tagged version straight from GitHub (the repo is public, so no token is needed):

```bash
npm install github:njarvis93/zg-wedding-design-system#v1.0.0
```

or pin a range in `package.json`: `"zg-wedding-design-system": "github:njarvis93/zg-wedding-design-system#semver:^1.0.0"`. To upgrade, change the tag.

```js
// once, at the app entry
import 'zg-wedding-design-system/tokens.css';   // CSS variables for both themes + @font-face
import 'zg-wedding-design-system/styles.css';   // component styles (mx- classes)
import 'zg-wedding-design-system/base.css';     // optional: page ground, ink and body font on <body>

// anywhere
import { Button, TabBar, Countdown } from 'zg-wedding-design-system';
import homeIcon from 'zg-wedding-design-system/assets/Icons/home.svg';
import tokens from 'zg-wedding-design-system/tokens.json';
```

- **Themes:** Costa (light) is the default. Set `data-theme="dark"` on `<html>` for Noche, for example from `prefers-color-scheme` or a user setting.
- **React:** a peer dependency (`>=18`); the package uses the app's React.
- **Fonts:** DM Sans and Space Grotesk ship inside the package and load through `tokens.css`; bundlers like Vite resolve their URLs.
- **Type styles:** every style in `tokens.json` is also a class, e.g. `className="mx-type-title-l"`.

## Making a new version

1. Change the sources: `src/` (components, types, styles), `project/tokens.json`, `project/fonts/`, `project/assets/`.
2. Run `npm run build` (plain Node, nothing to install). It regenerates `dist/` and the artifact bundle in `project/components/`.
3. Bump `version` in `package.json`, add a `CHANGELOG.md` entry, rebuild, commit, then tag and push:
   ```bash
   git tag v1.1.0 && git push origin main v1.1.0
   ```

GitHub checks on every push that the generated files match their sources (`npm run check`).
