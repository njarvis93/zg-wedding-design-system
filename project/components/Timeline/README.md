The day's program: time in Space Grotesk on the left, title and note on the right, rows split by `lavanda` hairlines inside one outlined card.

## Props
- `items`: `[{time, title, text?, tag?, highlight?}]` — `highlight` colors the time `rojo-texto` (the ceremony), `tag` adds a `pendiente` badge ("Hora dorada").

## Usage
Información → Programa. Unknown times stay as placeholders ("[hh:mm]"). A following-day event goes in its own `lavanda` card under its own eyebrow.
