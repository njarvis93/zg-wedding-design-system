The ceramic plate: blue petals, olive dots and a dashed ring around a centre of lemons, or the 'N&J' monogram.

## Props
- `size` (px, default 160), `monogram` (centre "N&J" instead of lemons), `label` (only when it carries meaning).

## Usage
One per hero: the save-the-date card (150px, bleeding off the corner), the desktop guest hero (230px, monogram, with lemon sprigs around it), the system board header (170px).
