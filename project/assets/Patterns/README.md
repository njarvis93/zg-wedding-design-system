The majolica tile: blue corner arcs, four blue petals, four olive inner petals, an orange centre and terracotta joint dots on cream. Code draws it with `MajolicaPattern` / `MajolicaStrip`; these files are for places that need an image.

- `majolica-tile.svg` — one 40×40 tile at full size. Repeat it as a background.
- `majolica-strip.svg` — a 440×22 band at tile scale .55 (desktop strip). Repeat-x and add the 2px `terracota` rule.
- `photo-placeholder.svg` — 240×120 at scale .8: the stand-in for a missing photo; overlay a small "foto" label on `crema`.
