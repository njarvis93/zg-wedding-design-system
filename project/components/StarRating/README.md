Five 40×44 star buttons for each partner's score on a proposal — `naranja` filled, `estrella-vacia` outlined.

## Props
- `value` (0–5), `onChange(n)`, `label` (group name, e.g. "Tu puntaje para Mediterráneo"), `max` (5).

## Usage
Proposal cards and the comparison table. Show the other partner's score beside it in `caption` ("Juan: 4").
