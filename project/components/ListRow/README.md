A row inside a card: optional avatar or numbered square, a bold title with a meta line, and a trailing value or badge.

## Props
- Lead: `initials` (40px avatar) or `number` (40px square in `leadTone`: `lavanda` · `pendiente` · `descartada`).
- `title`, `meta`, `trailing` (13px `texto-tenue`; `urgent` → `rojo-texto` 600; `strong` → 15px bold `marino`, for amounts), `badge` + `badgeTone`.
- `divider` (default true; set false on the last row), `href` (whole row is a link), `children` (extra content below, e.g. row actions).

## Usage
Definitions in progress ("4 · ¿Dónde hacemos la fiesta? · 12 días"), upcoming payments ("Reserva de la casa · $800.000"), latest RSVPs, the household list.
