The 'N&J' wordmark in Space Grotesk with the ampersand in `rojo` (or `naranja` on `marino`).

## Props
- `size`: default 22px (mobile header) · `lg` 26px (desktop header, sidebar). `onDark` — white letters, `naranja` ampersand.

## Usage
Top-left of every header. The full names ("Narvis & Juan") are set as a display headline, not as a logo.
