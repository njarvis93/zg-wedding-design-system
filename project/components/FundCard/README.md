A cash-fund card: icon tile, title, progress toward a goal, and a toggle that reveals the transfer details.

## Props
- `title`, `sub`, `icon` (default `plane`), `raised`, `goal`, `pct`, `cta`, `details`: `[[term, value]…]` shown in a `fondo` panel when open, `defaultOpen`.

## Usage
"Fondos" on the gift list (luna de miel, casa). Bank data stays behind the toggle and never appears on the public cover.
