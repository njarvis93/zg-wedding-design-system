Overlapping initials (−8px) with a white ring, showing who an invitation covers.

## Props
- `people`: `[{initials, name?, tone?}]` — tones cycle `lavanda` → `pendiente` → `descartada` when omitted.
- `label` — accessible summary (defaults to the names).
- `size` (default 36).

## Usage
"Tu invitación" card on the guest home: the household's members under the invitation text.
