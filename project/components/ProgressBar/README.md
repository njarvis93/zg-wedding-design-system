A square progress bar: `mayolica` on a `lavanda` track, or `naranja` on a translucent track inside a `marino` card.

## Props
- `value` 0–100, `label` (accessible name), `height` (10 in fund cards, 8 on web stat cards, 6 in app stat cards), `onDark` (for `marino` cards).

## Usage
Fund raised vs goal, paid vs budget. Always pair with the numbers in text ("$3,8 M pagado de $10 M").
