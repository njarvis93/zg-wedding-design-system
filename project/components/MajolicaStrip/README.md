The tile band along the top edge of every screen, with a 2px `terracota` rule.

## Props
- `size`: `mobile` (14px, tile scale .35) · `desktop` (22px, scale .55). `position`: `top` (rule below) · `bottom` (rule above — end of the desktop footer).

## Usage
Absolutely positioned at the very top of each page (`left:0; right:0; top:0`), content starting below it. Never inside cards.
