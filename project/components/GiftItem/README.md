A gift-registry tile: a photo area (majolica placeholder until there is a photo), title, price, and its reservation state.

## Props
- `title`, `price` (already in the guest's currency), `image` (URL; omitted → placeholder), `imageLabel`.
- `state`: `free` → primary "Lo regalo yo" · `mine` → "Reservado por ti" + quiet "Liberar" · `taken` → "Ya lo regalan" on `lavanda`. `onReserve`, `onRelease`.

## Usage
Two-column grid ("Para la casa"). End the section with "Esta página no procesa pagos…".
